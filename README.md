### Home Improvements Project

A Java-based application designed to track and manage residential home improvement tasks, tool inventories, and project timelines. This application focuses on robust data structures, null-safe file parsing, and reliable terminal/CLI execution. 

### 🚀 Features

* **Project Tracking:** Monitor progress on multi-step renovations.
* **Resource Management:** Manage lists of tasks and tool tracking safely.
* **Robust Exception Handling:** Implements defensive programming with safe null checks, avoiding common runtime crashes like NullPointerException.
* **Classpath File Loading:** Dynamic file streaming built with standard Java input stream libraries.

### 🛠️ Prerequisites & Installation

To run this application on your local machine, you need: 

* **Java Development Kit (JDK):** Version 8 or higher (Java 11+ recommended).
* **Git:** For source control management.

### Setup Instructions

### 💻 How to Run the Program

Compile the project using the standard Java compiler from your terminal or VS Code: 

bash

# Compile the primary Java application files
javac *.java

# Run the main program
java Main

Use code with caution.
